## Architecture

### Step 1: Wire the Brain
**Claude Code + Skills** - Your five core abilities:
- `metrics` — poll numbers
- `inbox` — read out today's email  
- `trends` — scan what's moving
- `plan` — write today's top 3
- `vault` — read + write memory

### Step 2: Build the Memory
The vault is everything JARVIS knows. It's just files.

```
vault/          ← Every report lands as markdown
raw/            ← Everything captured
wiki/           ← Distilled knowledge
outputs/        ← Everything JARVIS ships
```

**The rule:** If it's not in the vault, it didn't happen.

### Step 3: Add the Voice
Your audio never leaves the machine.

- 🎤 **Push to talk** — hold space, speak
- 🧠 **Local STT** hears you — audio never leaves
- 🔊 **Local TTS** answers out loud
- ⏱️ **Time:** ~15 minutes to wire

### Step 4: Build the Face
A dark terminal HUD for your OS:
- **System vitals** — what's running
- **Command deck** — next up
- **Schedule** — today's shape
- **Audio I/O** — live data from the vault

**One screen. No tabs.**
