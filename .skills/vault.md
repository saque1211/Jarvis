# Skill: Vault

The memory. Ask anything.

## What it does
- Reads everything JARVIS knows
- Queries across all notes
- Provides context + answers
- Learns from every interaction

## The Structure
```
vault/
  ├── daily/          ← Today's logs (briefing, plan, metrics, etc)
  ├── weekly/         ← Weekly reviews
  ├── projects/       ← Active projects
  ├── people/         ← People you know
  ├── ideas/          ← Ideas to explore
  └── archive/        ← Old projects
```

## Usage
```
"What did I do last Tuesday?"
"What's the status on [project]?"
"Tell me about [person]"
"Show me my progress"
```

## The Rule
**If it's not in the vault, it didn't happen.**

Everything important flows here:
- Reports (from other skills)
- Notes (from you)
- Learnings (from reflection)
- Context (for future you)

---

**Remember:** Your vault is your external brain. Treat it like one.
