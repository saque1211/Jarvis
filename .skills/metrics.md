# Skill: Metrics

Pull your numbers. Subs, views, followers — measured.

## What it does
- Fetches metrics from configured sources
- Logs them to vault with timestamp
- Reports trends

## Sources
- [ ] YouTube Analytics
- [ ] Twitter/X Analytics  
- [ ] Instagram Insights
- [ ] GitHub Stats
- [ ] Custom sources

## Usage
```
"Metrics pull"
"What are today's numbers?"
"Show me growth"
```

## Output
Metrics are logged to `vault/daily/metrics-YYYY-MM-DD.md`

---

**Remember:** Measure what matters. Everything else is noise.
