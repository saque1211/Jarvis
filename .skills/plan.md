# Skill: Plan

Write today's top 3 priorities.

## What it does
- Asks you: What are your top 3 today?
- You speak them (or type)
- JARVIS structures them
- Logs to vault for the day
- Reports back via TTS

## Usage
```
"Plan today"
"What's on my plate?"
"Set my priorities"
```

## Output
Plan logged to `vault/daily/plan-YYYY-MM-DD.md`

Format:
```markdown
# Today's Top 3 — {date}

1. [Priority 1]
2. [Priority 2]
3. [Priority 3]

---
Set at: {time}
```

---

**Remember:** Small singular aims beat big vague ones.
