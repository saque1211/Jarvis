# Skill: Inbox

Read today's email. The morning brief.

## What it does
- Pulls unread emails
- Summarizes important messages
- Reads them aloud via TTS
- Logs to vault

## Sources
- Gmail integration
- Custom email sources

## Usage
```
"Morning brief"
"Read my inbox"
"What emails do I have?"
```

## Output
Summary logged to `vault/daily/inbox-YYYY-MM-DD.md`

---

**The rule:** If it's urgent, it surfaces. Otherwise, it waits in the vault.
