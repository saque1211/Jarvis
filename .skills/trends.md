# Skill: Trends

Scan what's moving.

## What it does
- Monitors trending topics
- Scans social feeds for signals
- Reports what's rising
- Logs to vault

## Sources
- Twitter/X Trends
- Hacker News
- Product Hunt
- Reddit trending
- Custom RSS feeds

## Usage
```
"What's trending?"
"Scan the web"
"Show me what's hot"
```

## Output
Trends logged to `vault/daily/trends-YYYY-MM-DD.md`

---

**The strategy:** Trends compound attention. Know the signal before the noise.
